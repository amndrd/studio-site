Modélisés maison, sans crédit nécessaire :
- le clavier (pavé numérique, AZERTY), depuis le 15/11 : `outils/clavier_magic.py` et `keyboard_mk` dans `outils/blender/objets-poste.py` ;
- le Mac Studio, depuis le 15/11 : `mac_studio_maison` dans `objets-poste.py`. La géométrie et les matières sont générées par notre code, sans reprendre ni le maillage ni les textures Sketchfab.
  - Les détails viennent de photos du produit : ports verticaux, fente SD, base ronde, logo d'après la silhouette publique.
  - Les proportions (taille, courbe des angles, base, position des ports et du logo) ont été mesurées sur les rendus de l'ancien modèle pour obtenir un rendu identique.

L'ancien modèle Sketchfab du Mac Studio (rtql8d, CC BY-NC) a été supprimé du dossier le 15/11, avec le clavier et l'iPhone Sketchfab, qui ne servaient plus.

Il n'y a donc plus aucun modèle sous licence non commerciale dans le décor.

Modèles et textures Poly Haven : licence CC0, aucun crédit obligatoire.

Objets du bureau (étape 8, 15/11) : modèles choisis et téléchargés par toi (zips dans `outils/assets/modeles`, dézippés dans `outils/assets/sketchfab/<modèle>/_archive`).
Le tampon du gobelet est une création du studio, pour un café inventé (aucune marque réelle visible).
Le pack de canettes (Soda Cans 3D pack, Subdivision Productions, CC BY 4.0) n'est plus dans le décor depuis le choix du 15/11 : à recréditer seulement s'il revient.
Décor autour du bureau (étape 10, 16/11) : la corbeille, les boulettes et le ventilateur de table sont tes modèles (zips dans `outils/assets/newmodels`, dézippés de la même façon). La marque réelle du ventilateur de table est retirée : ses lettres en relief sont supprimées et un capot uni recouvre le badge.
Retenu le 16/11 : la piste D, ventilateur de table blanc. Le ventilateur sur pied (Oscillating Pedestal Fan, hippostance, CC BY 4.0) n'est pas dans le décor : à recréditer seulement s'il revient.
Les ventilateurs, plantes et pots modélisés pour la première série (A, B, C) ne sont plus dans le décor.
La sculpture n'est pas encore dans le décor (gardée pour l'étape du décor du labo).

Le musée a publié la numérisation lui-même, ce qui laisse penser que la diffusion est permise. Pour un site public, une confirmation écrite du musée (mmorera.paeria.cat) reste plus sûre.
